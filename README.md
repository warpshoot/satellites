# SATELLITES

盤面を星空に見立てて音源の星を置き、核を中心に周回させて放置するアンビエント生成ツール。

**https://warpshoot.github.io/satellites/**

音楽の知識がなくても、置いて放置するだけで鳴り続ける音の場を作れる。
星を置くと音が鳴り、核からの距離が音量・リバーブ・高域の減衰を決める。
周回させれば、触らないまま音像が変わり続ける。

## 使い方

1. 開いて画面をタップする（音は最初のタップまで鳴らない）
2. 盤面の空いているところをタップして、音源を選んで星を置く
3. 星を選んで、パネルから音色と軌道をいじる
4. あとは放置する

- **音源** DRONE（持続音）/ NOISE（風や雨の質感）/ GRAIN（粒）/ DRIVE（歪んだ唸り）
- **核からの距離** 近いほど大きく、遠いほど静かでリバーブが深く、高域が落ちる
- **周回** 正円なら音量は一定、つぶれた軌道なら近日点で大きく鳴る
- **軌道傾斜** 面を奥へ倒すと、距離が周期的に変わる

同時に鳴らせるのは8つまで。置いた内容はブラウザに保存され、次に開くと戻る。

## 作り

素の HTML / CSS / JavaScript（ES Modules）。ビルドステップなし、外部ライブラリなし。
音は Web Audio API だけで鳴らしている。そのまま静的ホストに置けば動く。

開発の前提と、これまでに捨てた設計の理由は [CLAUDE.md](./CLAUDE.md) に書いてある。
