# SATELLITES パッチの書き方（AI 向け）

このファイル1枚で足りるように書いてある。リポジトリの他のファイルは読まなくていい。

あなたに頼まれているのは、**SATELLITES のパッチ JSON を1つ吐き出すこと**。
出力は JSON だけでいい。ユーザーはそれをアプリの「JSON を貼り付けて読む」に流し込む。

- アプリ: https://warpshoot.github.io/satellites/
- 盤面を星空に見立てて音源の星を置き、中心の核を周回させて放置する、アンビエント生成ツール

---

## 1. 世界の決まり

**核は盤面のど真ん中 `(0.5, 0.5)` に固定**されていて動かない。星はそこを周回するか、止まっている。

音は**核からの3次元距離だけ**で決まる。視点からの距離という概念は無い。

| 何が | 何を決める |
|---|---|
| 核からの距離 | ドライの減り方（逆二乗）、ウェット／ドライ比、空気の吸収（高域）、星の大きさ |
| 横位置 `x` | パン（0 = 左 / 1 = 右） |
| 縦位置 `y` | 音色の傾き。低域と高域を逆向きに ±9dB 動かす。上（y 小）が明るい |
| 面からの浮き `z` | 軌道を傾けたときに生まれる。にじみ（送り増・直接音減）と前後（奥は高域 -4.5dB） |
| `vol` | その星自身の音量。距離とは別に掛かる |

距離の効き方は `near = 1 / (1 + (d / 0.32)²)`（`d` は核からの距離）。
`near` が 1 で核のすぐそば、0 で遠い。**距離に床は無い**。`(0.5, 0.5)` から 0.32 離れると `near = 0.5`。

**遠ざけることは「小さくする」ではない。** 送りはドライよりゆっくり落ちるので（`near^0.35` 対 `near^1.3`）、
遠い星は音量が下がるのではなく**残響に沈む**。実測で、近い星のウェット／ドライ比が 0.40、
`near = 0.2` の星が 3.88。遠景を作りたいなら小さい `vol` ではなく、遠い位置を使う。

## 2. JSON の骨格

```json
{
  "version": 3,
  "master": {
    "gain": 0.8,
    "tuning": { "root": "C", "scale": "pentaMinor" },
    "reverb": { "length": 3.0, "decay": 2.5 },
    "delay": { "time": 420, "feedback": 0.35, "sync": true },
    "pulse": true,
    "sky": "noise",
    "follow": false
  },
  "voices": [ /* 最大 8 個 */ ]
}
```

星1つはこう：

```json
{
  "id": "v1-aaaaa",
  "type": "drone",
  "x": 0.42, "y": 0.55,
  "look": "band",
  "vol": 0.85,
  "orbit": true,
  "orbitPeriod": 180,
  "orbitRadius": 0.22,
  "orbitPhase": 0,
  "orbitEcc": 0.35,
  "orbitAngle": 20,
  "orbitIncl": 0,
  "orbitDir": "prograde",
  "common": { "attack": 6, "release": 10, "drift": 0.4, "reverbSend": 0.5, "delaySend": 0.1 },
  "params": { "freq": 55, "count": 3, "detune": 12, "wave": "sawtooth", "width": 0.6 }
}
```

## 3. 黙って落とされる書き方（ここが一番の地雷）

読み込みは `sanitize()` という関門を通る。**エラーは出ない。黙って落ちる。**

1. **`"version": 3` を忘れると、パッチ全体が捨てられて空になる。** 必ず入れる
2. **`type` が `drone` / `noise` / `grain` / `drive` のどれでもない星は、丸ごとスキップされる。**
   8個書いたのに5個しか出ない、という形で現れる
3. **9個目以降は切られる。** 同時発音は 8 点まで
4. `x` / `y` は `0〜1` に丸められる。盤面の外に置く指定は JSON 経由では通らない
5. `id` は星ごとに違う文字列にする。省くと自動で振られるが、**重複させると壊れる**
6. 範囲外の数値は黙ってクランプされるか、既定値に戻される。
   数値でない値（文字列の `"0.5"` など）は既定値に戻る。**数値は数値で書く**
7. **`orbitRadius: null` は「置いた位置から半径を割り出す」の意味。0 ではない。**
   `orbit: true` にして `orbitRadius` を数値で書くと、`x` / `y` は初期位置の意味を失い、
   軌道のほうが位置を決める
8. **ソロとミュートは存在しない。** 書いても無視される
9. **基音と音階はマスターに1組だけ。** 星ごとの音程指定は無い（後述）

## 4. マスター

| キー | 範囲 | 既定 | 意味 |
|---|---|---|---|
| `gain` | 0〜1 | 0.8 | マスター音量。リミッタの後ろに掛かる |
| `tuning.root` | `C` `C#` `D` `D#` `E` `F` `F#` `G` `G#` `A` `A#` `B` | `C` | 基音 |
| `tuning.scale` | `off` `chromatic` `major` `minor` `dorian` `pentaMinor` `wholeTone` `fifths` | `pentaMinor` | 音階 |
| `reverb.length` | 0.5〜8（秒） | 3.0 | リバーブの長さ |
| `reverb.decay` | 1〜6 | 2.5 | 減衰の速さ。大きいほど早く消える |
| `delay.time` | 50〜2000（ms） | 420 | ディレイ時間 |
| `delay.feedback` | 0〜0.85 | 0.35 | 0.85 を超えさせない（発振する） |
| `delay.sync` | `true` / `false` | `true` | true だと、一番速い星の周回に合わせてディレイ時間が決まり、`delay.time` は無視される |
| `pulse` | `true` / `false` | `true` | 音に合わせて星を動かすか（見た目だけ） |
| `sky` | `noise` `sparse` `none` | `noise` | 背景の星（見た目だけ） |
| `follow` | `true` / `false` | `false` | 選んだ星を画面中心に置くか（見た目だけ） |

**音程は鳴らす直前に一番近い音度へ吸着する。** 効くのは DRONE と DRIVE の `freq`、
GRAIN の粒ごとの音程。デチューンは吸着しない（潰すと重ねる意味が消えるため）。
`scale: "off"` で素通しにできる。

音階の中身：
`major` = 0,2,4,5,7,9,11 ／ `minor` = 0,2,3,5,7,8,10 ／ `dorian` = 0,2,3,5,7,9,10 ／
`pentaMinor` = 0,3,5,7,10 ／ `wholeTone` = 0,2,4,6,8,10 ／ `fifths` = 0,7

`fifths` は 5度と根音だけなので、何を置いても濁らない。迷ったらここか `pentaMinor`。

## 5. 星に共通のキー

| キー | 範囲 | 既定 | 意味 |
|---|---|---|---|
| `id` | 文字列 | — | 星ごとに固有。`"v1-abc12"` のような形 |
| `type` | `drone` `noise` `grain` `drive` | — | 音源種別。間違えると星ごと消える |
| `x` `y` | 0〜1 | — | 盤面の位置。核は `(0.5, 0.5)` |
| `look` | `solid` `ring` `hollow` `crescent` `band` `binary` | 種別ごと | 見た目だけ。音には無関係 |
| `vol` | 0〜1 | 0.85 | 星自身の音量 |
| `orbit` | `true` / `false` | `false` | 周回するか |

`common`（全種別で共通）:

| キー | 範囲 | 既定 | 意味 |
|---|---|---|---|
| `attack` | 0.01〜20（秒） | 2.0 | 立ち上がり |
| `release` | 0.01〜30（秒） | 4.0 | 消え際 |
| `drift` | 0〜1 | 0.3 | ゆらぎ。噛み合わない正弦を重ねて、戻ってこない揺れを作る |
| `reverbSend` | 0〜1 | 0.4 | リバーブ送り（距離による送りとは別に足される） |
| `delaySend` | 0〜1 | 0.15 | ディレイ送り |

**`drift` を 0 にしない。** 放置して聞くものなので、これが無いと数分で状態が止まって聞こえる。

## 6. 周回

`orbit: true` のときだけ意味を持つ。

| キー | 範囲 | 意味 |
|---|---|---|
| `orbitPeriod` | 5〜600（秒） | 1周の時間 |
| `orbitRadius` | 0.02〜2、または `null` | 軌道の大きさ。`null` は `x`/`y` から割り出す |
| `orbitPhase` | ラジアン | 開始角。星ごとにずらす |
| `orbitEcc` | 0〜0.9 | つぶれ具合。0 = 正円 |
| `orbitAngle` | 0〜360（度） | 軌道の向き |
| `orbitIncl` | 0〜90（度） | 面を奥へ倒す角度 |
| `orbitDir` | `prograde` / `retrograde` | 順行 / 逆行 |

ここが**鳴りに直結する**ところ：

- **正円（`orbitEcc: 0`）は核からの距離が変わらないので、音量も音色も動かない。**
  つぶれた軌道だけが呼吸する（近日点で大きく鳴る）
- **正円は傾けても距離が変わらない。** 回転させているだけなので当然で、
  実測でも傾斜45度・正円の音量振幅は 0.9dB しかなかった。
  ただし `orbitIncl` は「浮き」として別口で効く。傾斜90度・正円を1周させた実測で、
  ドライは 0.5dB しか動かないのに、ウェットが 3.7dB、高域が 3.6dB 動く。
  **傾斜は音量ではなく「にじみ方」を動かす**
- **`orbitPeriod` を揃えない。** 揃うと全部の動きが噛み合って、周期的な「小節」が生まれる。
  互いに割り切れない値（例: 47 / 73 / 111 / 181 秒）にすると、同じ配置に戻ってこない
- **`orbitPhase` も散らす。** 揃うと全部が同時に近づいて、そこだけ音が膨らむ

## 7. 種別ごとの `params`

### `drone` — 持続音。土台
| キー | 範囲 | 既定 |
|---|---|---|
| `freq` | 20〜500（Hz） | 80 |
| `count` | 1〜5（整数） | 3 |
| `detune` | 0〜50（cent） | 12 |
| `width` | 0〜1 | 0.6 |
| `wave` | `sawtooth` `triangle` `sine` `square` | `sawtooth` |

**`count` はそのまま発音数を食う。** `count: 5` の DRONE は1点で5ボイス相当。
`square` と `sawtooth` は倍音が多いので、重ねると簡単に濁る。土台は `triangle` か `sine` が安全。

### `noise` — 風や雨の質感
| キー | 範囲 | 既定 |
|---|---|---|
| `center` | 20〜12000（Hz） | 800 |
| `q` | 0.5〜30 | 2.0 |
| `swellDepth` | 0〜1 | 0.3 |
| `swellRate` | 0.02〜2（Hz） | 0.15 |
| `width` | 0〜1 | 0.8 |

`q` を上げると帯域が細くなり、ノイズが音程を持ち始める。`q: 20` あたりで「鳴っている」に寄る。

### `grain` — 粒
| キー | 範囲 | 既定 |
|---|---|---|
| `interval` | 0.05〜5（秒） | 1.2 |
| `jitter` | 0〜100（%） | 40 |
| `grainLen` | 20〜2000（ms） | 300 |
| `center` | 100〜4000（Hz） | 700 |
| `spread` | 0〜2400（cent） | 600 |
| `width` | 0〜1 | 0.7 |
| `wave` | `sine` `triangle` `noise` | `sine` |

**`jitter` を 0 にしない。** 等間隔の粒はメトロノームになる。40〜70% が呼吸する。
`interval` が短く `grainLen` が長いと粒が重なって雲になる（密度が上がっても音量は一定に保たれる）。

### `drive` — 歪んだ唸り
| キー | 範囲 | 既定 |
|---|---|---|
| `freq` | 20〜300（Hz） | 55 |
| `drive` | 0〜1 | 0.5 |
| `filterPos` | `pre` / `post` | `post` |
| `swellRate` | 0.02〜1（Hz） | 0.08 |
| `swellDepth` | 0〜100（cent） | 30 |

**一番場所を取る音。** 1つで足りる。2つ以上入れると他が全部その後ろに隠れる。
アンビエントとして置くなら核から遠く（`near` 0.3 以下）へ。

## 8. 良い配置の作り方

聞ける状態にするための、実際に鳴らして分かっていること。

- **8点を埋めようとしない。** 4〜6点が呼吸する。
  8点全部を核の近くに詰めると、リミッタが常時働いて全部が平らになる
- **役割を分ける。** 土台（DRONE を核の近くに1〜2）／ 質感（NOISE を中距離に1〜2）／
  出来事（GRAIN を遠くに1〜2）／ 陰（DRIVE を遠くに0〜1）
- **距離をばらけさせる。** 全部を同じ距離に置くと平面になる。
  核のすぐそば（距離 0.05〜0.15）、中景（0.25〜0.4）、遠景（0.5〜0.8）に散らす
- **`attack` を散らす。** 全部が同じ立ち上がりだと「一斉に開いた」と聞こえる。
  2秒から12秒までばらけさせる
- **低音は1つに任せる。** DRONE と DRIVE の `freq` を両方 60Hz 付近に置くと、
  唸りが出て濁る。片方を 2オクターブ上へ
- **`y` で音色を分ける。** 明るい星（y 0.2〜0.35）と暗い星（y 0.65〜0.8）を混ぜると、
  同じ音源でも別の層に聞こえる
- **全部を周回させない。** 動かない星が1つあると、周りが動いているのが分かる

この指針で組んだ6点のパッチを実際に20秒鳴らして測ると、ピーク -4.3 dBFS、
リミッタの削減は最大 1.98dB に収まった。8点を核の近くに詰めると常時 7dB 潰れて、
粒が落ちるたびに土台が凹む。**削減が常時 3dB を超えていたら、詰めすぎ**と思っていい。

## 9. 出力するときのお願い

- **JSON だけを出す。** コメントを混ぜない（JSON にコメントは書けない）
- 8点を超えない。`version: 3` を入れる。`id` を重複させない
- 数値は数値で書く（`0.5` であって `"0.5"` ではない）
- どういう情景を狙ったか、JSON の外に1〜2行で添えてくれると、ユーザーが調整しやすい
